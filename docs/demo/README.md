# NexusOne product walkthrough

A 60-second, 1920 × 1080 landscape MP4 with English captions, built from real app screens.

Download `NexusOne-60s.mp4` to watch the walkthrough. `NexusOne-60s.srt` contains the subtitle track.

The walkthrough covers sign-in, cited knowledge answers, live ticket lookups, ticket approval previews, role-based access controls, personal memory, feedback, and the mobile layout. Screens use the repository’s fictional development data.
