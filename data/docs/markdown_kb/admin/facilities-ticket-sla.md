# Facilities Ticket SLA

## Access Notice

This document is restricted to Admin Ops, managers, and the CEO.

## SLA Matrix

| Ticket type | Priority | Target response | Target resolution |
|---|---|---:|---:|
| Building access outage | Urgent | 1 hour | Same day |
| Health or safety issue | Urgent | 1 hour | Same day |
| Desk equipment blocker | Normal | 1 working day | 3 working days |
| Visitor pre-registration | Normal | 1 working day | Before visit |
| Facilities maintenance | Low | 2 working days | 7 working days |

## Escalation

Managers can escalate onboarding blockers and accessibility needs. Admin Ops should record supplier dependency when resolution depends on a fictional vendor.

## Visibility

Managers may see status summaries for team-impacting tickets, but not private notes from Admin Ops.
