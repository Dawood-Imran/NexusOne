# Desk Equipment Request

## Summary

Employees can request standard desk equipment through the Admin Portal. Home office monitor reimbursement is handled by Finance, while company-owned office equipment is handled by Admin.

## Standard Items

- Office chair adjustment or replacement.
- External keyboard and mouse.
- Desk lamp.
- Monitor for office desk.
- Docking cable or display cable.

## Request Steps

1. Create an Admin ticket under `Desk equipment`.
2. Select office location or remote work status.
3. Add item type, reason, and manager approval if the request is outside standard allocation.
4. Wait for Admin assignment or pickup instructions.

## Finance Boundary

Do not submit home office purchases to Admin. Use the Finance Portal for reimbursable employee purchases.
