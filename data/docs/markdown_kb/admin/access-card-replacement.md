# Access Card Replacement

## Summary

Employees should report lost, damaged, or expired office access cards immediately. Admin may temporarily suspend a lost card before issuing a replacement.

## Request Steps

1. Create an Admin ticket with category `Access card`.
2. Select lost, damaged, expired, or name correction.
3. Include office location and last known use if the card is lost.
4. Collect replacement card from reception after Admin confirms identity.

## Temporary Access

Reception may issue temporary visitor-style access for one working day while the replacement is prepared. Employees must not borrow another employee's access card.

## Security Note

Lost cards that may have been stolen should also be reported to IT security if a laptop or company device was lost at the same time.
