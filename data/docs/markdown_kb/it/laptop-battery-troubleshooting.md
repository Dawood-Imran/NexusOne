# Laptop Battery Troubleshooting

## Summary

Employees should try basic checks before creating a device ticket. IT prioritizes battery tickets based on work impact, device age, charging behavior, and whether the employee has an approved backup device.

## Checks Before Ticket

1. Restart the laptop and apply pending operating system updates.
2. Test with the original company charger.
3. Check whether battery health shows `Service recommended` or equivalent.
4. Reduce screen brightness and close unused video or build processes.
5. Note how long the battery lasts from 100 percent to 20 percent.

## Create A Ticket

Create an IT device ticket if the battery drains in less than 90 minutes, fails to charge, swells, overheats, or blocks remote work.

## Ticket Fields

Include asset tag, operating system, charger model, battery health screenshot, drain time, and whether the device is needed for a customer commitment.
