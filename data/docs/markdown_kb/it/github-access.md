# GitHub Access Request

## Summary

GitHub access is granted only for work repositories. Engineering employees usually receive baseline organization access during onboarding, while repository-level permissions require manager or service-owner approval.

## Request Steps

1. Create an IT access ticket with category `Software access`.
2. Enter `GitHub` as the target system.
3. Include repository or team name, access level, and business reason.
4. Add approving manager and service owner.
5. Wait for IT to confirm SSO group assignment.

## Access Levels

Read access is used for code review, triage, and onboarding. Write access requires active contribution responsibility. Admin access is restricted and is not covered by this employee-facing process.

## Removal Rules

GitHub access is removed automatically during offboarding or team transfer. Managers must open a change ticket if a user no longer needs access before offboarding.
