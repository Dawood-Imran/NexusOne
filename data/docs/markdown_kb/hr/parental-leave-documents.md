# Parental Leave Documents

## Summary

Employees requesting parental leave must submit documents through HRIS. Requirements vary by region, but employees should start the request as early as possible.

## Required Documents

| Region | Documents |
|---|---|
| Pakistan | Medical certificate or birth documentation, expected leave dates |
| UAE | Birth notification or adoption documentation, Emirates ID copy if required |
| UK | Expected week of birth or adoption match notice |
| USA | Birth or placement documentation and state-specific forms when applicable |

## Submission Steps

1. Create leave request in HRIS.
2. Attach required documents.
3. Add expected start date, expected return date, and handover owner.
4. Submit for manager visibility and HR review.

## Privacy

Medical details should be uploaded only to HRIS or an HR ticket. Do not send medical documents through Slack or email unless HR asks for a secure upload fallback.
