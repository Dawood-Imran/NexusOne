# HR Ticket Categories

## Summary

HR tickets route employee questions to the right owner. Employees can see their own tickets. HR can see the HR queue based on role permissions.

## Categories

| Category | Use for | Standard SLA |
|---|---|---:|
| Payroll issue | Salary, payslip, bank, deduction questions | 3 working days |
| Leave support | Leave balance, parental leave, sick leave documents | 2 working days |
| Benefits | Insurance, wellness, regional benefit questions | 4 working days |
| HRIS profile | Name, address, tax, emergency contact corrections | 2 working days |
| Employee relations | Sensitive workplace concern | 1 working day |

## Required Fields

Every HR ticket should include category, region, employee ID, brief issue summary, and supporting documents when applicable.

## Sensitive Tickets

Employee relations and medical-document tickets are restricted. Employees should not include sensitive HR details in public Slack channels.
