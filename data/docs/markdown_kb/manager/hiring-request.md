# Hiring Request

## Access Notice

This document is restricted to managers, HR, executives, and the CEO. It explains manager-side hiring request workflow.

## Summary

Managers open a hiring request when a role is approved in plan or when replacement hiring is needed. Requests must include business justification, budget owner, role level, location, and expected start quarter.

## Request Steps

1. Open HRIS and select `Hiring request`.
2. Choose backfill, planned headcount, or exceptional hire.
3. Add role title, department, reporting manager, location, and employment type.
4. Attach job description and budget code.
5. Submit for HR and Finance review.

## Backend Engineer Example

A backend engineer request should include service ownership need, delivery risk, expected technology stack, interview panel, and whether AWS or GitHub access is required during onboarding.
