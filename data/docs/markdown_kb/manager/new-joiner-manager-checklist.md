# New Joiner Manager Checklist

## Access Notice

This document is restricted to managers, HR, executives, and the CEO.

## Before Day One

1. Confirm job title, team, buddy, start date, and onboarding plan.
2. Review required systems: Slack, Jira, GitHub, AWS, HRIS, and finance tools.
3. Ask IT to prepare access for role-specific tools.
4. Confirm Admin has assigned desk or remote equipment path.

## First Week

Set goals for week one, assign starter tasks, schedule daily check-ins, explain service ownership, and review security expectations.

## Engineering New Joiners

For engineering roles, confirm GitHub team, AWS account need, service ownership context, deployment process, and on-call introduction.
