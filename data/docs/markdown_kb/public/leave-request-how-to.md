# Leave Request How-To

## Summary

Employees request annual leave, sick leave, parental leave, unpaid leave, and work-from-abroad exceptions through HRIS. The reporting manager approves most leave types before HR performs policy checks.

## Request Steps

1. Open HRIS and select `Time off`.
2. Choose the leave type and region.
3. Enter start date, end date, half-day selection if needed, and handover notes.
4. Attach medical or parental leave documents when required.
5. Submit for manager approval.

## Approval Flow

Annual leave routes to the reporting manager. Sick leave longer than two working days routes to manager and HR. Parental leave routes to HR after manager visibility. Work-from-abroad requests require manager, HR, and Admin review.

## Good Handover Notes

Include current project status, customer commitments, blockers, and backup owner. Engineering employees should include Jira boards, release windows, and on-call swaps.
