# Ticket Creation Guide

## Confirmation Boundary

Ticket guidance is informational and does not submit a ticket. Copilot creates IT, HR, or Admin tickets only after an explicit request and asks for missing details before writing.

## Supported Types

- IT: software or cloud access, laptop or device issue, VPN, and MFA.
- HR: payroll, benefits, leave support, and onboarding.
- Admin: access card, desk equipment, visitor, and facilities.

## Required Information

Provide the team, category or type, short description, and priority when known. Add type details: IT access needs target system or environment and business reason; HR needs category, region, employee ID, issue summary, and supporting documents when applicable; Admin needs location, item, and reason.

## Next Steps

1. Ask for guidance without creating anything, or explicitly say “Create an IT, HR, or Admin ticket” when ready to submit.
2. Include team, category, priority, and description; Copilot asks a bounded clarification question for missing details.
3. After completion, Copilot returns the ticket's safe status and next step; guidance never claims creation occurred.
